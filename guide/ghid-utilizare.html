GHID DE UTILIZARE

Site-ul tău personal

Cum îl rulezi, cum publici articole și proiecte, cum îl pui online pe Cloudflare Pages și cum rezolvi erorile frecvente.

1. Ce conține proiectul

Site-ul e făcut cu Astro: scrii conținut în fișiere Markdown (.md), iar Astro le transformă în pagini HTML. Nu există bază de date sau panou de admin. Tot ce schimbi e un fișier text.

Ce vrei să schimbiFișierul
Articolesrc/content/posts/ (un fișier per articol)
Proiectesrc/content/projects/ (un fișier per proiect)
Textul din Aboutsrc/content/pages/about.md
Pagina Nowsrc/content/pages/now.md
Work, realizări, linkuri, programul de pe monitorsrc/data/site.ts
Culorile temelor dark/lightsrc/styles/tokens.css
Poza din ramăpublic/img/me.webp
CV-ul descărcabilpublic/cv/David_Malutan_CV.pdf
Videouri pentru proiectepublic/videos/

2. Rulează site-ul pe calculatorul tău

Ai nevoie de Node.js (îl ai deja instalat). Deschide un terminal în folderul site:

npm install      # o singură dată, instalează pachetele
npm run dev      # pornește site-ul local

Deschide http://localhost:4321 în browser. Cât timp rulează npm run dev, orice fișier salvat se vede imediat în pagină. Oprești serverul cu Ctrl + C.

Înainte de publicare, verifică build-ul de producție:

npm run build    # dacă apare o eroare aici, nu publica încă

3. Publică un articol nou

Pasul 1: creează fișierul

În src/content/posts/ creează un fișier cu numele articolului, fără spații, de exemplu primul-meu-hackathon.md. Numele fișierului devine adresa: /posts/primul-meu-hackathon.

Pasul 2: scrie antetul (frontmatter) și textul

---
title: What I learned at Cluj Hackathon
date: 2026-11-20
description: 48 hours, one parking app and a pitch.
draft: false
---

Primul paragraf al articolului.

## Un subtitlu

Text **îngroșat**, *italic*, [un link](https://exemplu.com) și `cod`.
CâmpCe înseamnă
titleTitlul afișat în listă și pe pagină.
dateData, obligatoriu în formatul AAAA-LL-ZZ. Articolele se ordonează după ea.
descriptionO frază scurtă, apare sub titlu și în RSS.
drafttrue = ascuns de pe site (ciornă). false = publicat.

Pasul 3: publică

git add .
git commit -m "Post: What I learned at Cluj Hackathon"
git push

Cloudflare reconstruiește site-ul automat. Articolul apare online în 1–2 minute.

Imagini în articol: pune imaginea în public/img/ și scrie în articol ![descriere](/img/numele-imaginii.webp).

4. Adaugă un proiect

Creează un fișier în src/content/projects/. Câmpul status decide ce se întâmplă la click:

statusComportament
liveTitlul deschide site-ul publicat (câmpul url) într-un tab nou.
demoCu video: titlul deschide videoul într-o fereastră. Fără video: eticheta „Video coming soon”.
soonEticheta „Coming soon”, fără link.

Exemplu: proiect publicat

---
title: Momentifly
short: MOMENTIFLY          # textul de pe cotorul cărții din scenă
year: 2026
description: Time management meets wellness.
stack: [Angular, Spring Boot, PostgreSQL]
status: live
url: https://adresa-ta.com
repo: https://github.com/David-Mal/momentifly   # opțional
order: 1                   # poziția în listă (1 = primul)
---

Exemplu: proiect cu video

---
title: Airplanes
short: AIRPLANES
year: 2024
description: The pen-and-paper game against a min-max AI.
stack: [Python]
status: demo
video: /videos/airplanes.mp4
poster: /videos/airplanes.webp
order: 6
---
Fiecare proiect apare automat ca o carte în teancul de pe birou. Cu mai mult de 7 proiecte teancul devine prea înalt: păstrează acolo doar ce vrei să arăți primul.

5. Înregistrează și comprimă un video

  1. Scrie întâi 3–4 pași pe care îi arăți (pornești aplicația, 2–3 acțiuni care arată ce poate).
  2. Înregistrează 15–30 de secunde, fără sunet, în 1080p. Pe Windows: Win + G (Game Bar) sau OBS. Ascunde notificările și taburile personale.
  3. Comprimă clipul (ai deja ffmpeg instalat):
ffmpeg -i clip.mp4 -vf "scale=1280:-2,fps=24" -an -c:v libx264 -crf 28 -preset slow -movflags +faststart airplanes.mp4

Imaginea de previzualizare (posterul), din secunda 3:

ffmpeg -i clip.mp4 -ss 00:00:03 -frames:v 1 airplanes.webp

Copiază ambele fișiere în public/videos/, completează video și poster în fișierul proiectului, apoi publică (pasul 3 de la articole).

Ține fiecare video sub ~3 MB. Dacă iese mai mare, crește -crf la 30–32 sau scurtează clipul.

6. Schimbă textul, poza și alte detalii

  • Fraza personală și About: editezi src/content/pages/about.md. Primul paragraf apare mare, ca titlu.
  • Pagina Now: src/content/pages/now.md. Schimbă și data din updated.
  • Work, realizări, GitHub, LinkedIn, e-mail: src/data/site.ts. E-mailul e scris invers în câmpul mailReversed, ca să nu-l găsească boții de spam.
  • Programul de pe monitor: lista bootProgram din src/data/site.ts. Maxim ~30 de caractere pe linie, ca să încapă pe ecran. Pune sintaxa reală a limbajului tău.
  • Poza din ramă: înlocuiește public/img/me.webp cu o poză portret, cu același nume.
  • Culorile: src/styles/tokens.css, separat pentru dark și light.

7. CV-ul

CV-ul public stă în public/cv/David_Malutan_CV.pdf și e folosit de butoanele „Download CV” și de pagina /cv. Versiunea de pe site nu conține numărul de telefon. Când îți actualizezi CV-ul, exportă o versiune nouă fără telefon și înlocuiește fișierul, păstrând exact același nume.

8. Pune site-ul online pe Cloudflare Pages

  1. Creează întâi repository-ul pe GitHub: github.com/new, nume site, gol (fără README, .gitignore sau licență). Abia apoi faci push, altfel apare eroarea „Repository not found”.
  2. Din folderul proiectului (cel care conține site/): 
    git init
git add .
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/David-Mal/site.git
git push -u origin main
    Fișierul .gitignore din rădăcină exclude deja materialele brute (videoul original etc.), iar site/.gitignore exclude node_modules.
  3. Intră pe dash.cloudflare.com → Workers & Pages → Create → Pages → Connect to Git și alege repository-ul.
  4. La setări: Framework preset = Astro, Root directory = site, Build command = npm run build, Build output directory = dist. Apasă Save and Deploy.
  5. După 1–2 minute primești o adresă de tipul numele-tau.pages.dev.
  6. Scrie adresa finală în astro.config.mjs la site: (folosită pentru RSS, sitemap și previzualizări pe rețele sociale) și publică din nou.

Domeniu propriu (opțional)

Cumperi un domeniu (de exemplu din Cloudflare Registrar), apoi în proiectul Pages: Custom domains → Set up a domain. Certificatul HTTPS se face automat.

9. Funcții ascunse ale site-ului

  • Lampa sau butonul din colț comută între noapte (dark) și zi (light). Alegerea se păstrează la următoarea vizită.
  • Monitorul „rulează” programul din bootProgram la prima vizită. Un click îl sare.
  • Avionul de hârtie zboară la click. Al treilea click deschide proiectul Airplanes.
  • Tasta ` deschide un terminal. Încearcă help și sudo hire-david.

10. Erori frecvente

Mesaj / simptomCauză și rezolvare
InvalidContentEntryDataError la buildAntetul unui fișier .md are o greșeală: lipsește un câmp obligatoriu, data nu e AAAA-LL-ZZ, sau status nu e live/demo/soon. Mesajul spune fișierul și câmpul.
url: Invalid urlLinkul trebuie să înceapă cu https://.
Articolul nu apareVerifică draft: false și că fișierul e în src/content/posts/ cu extensia .md.
Imaginea sau videoul nu se încarcăCalea începe cu / și nu conține public: /videos/x.mp4, nu public/videos/x.mp4. Numele fișierelor sunt sensibile la litere mari.
Port 4321 is in useMai rulează un npm run dev în alt terminal. Oprește-l cu Ctrl + C.
Antetul are linii roșii în editorAntetul trebuie să înceapă și să se termine cu ---, iar listele se scriu [A, B, C].
Estethis se încarcă greuNormal: găzduirea gratuită Render „adoarme” serverul. Prima vizită poate dura un minut.
Build-ul eșuează pe Cloudflare, dar local mergeVerifică în Cloudflare că output-ul e dist. Dacă eroarea pomenește versiunea de Node, adaugă în setările proiectului variabila NODE_VERSION = 22.
